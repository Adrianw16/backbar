# backbar
Ordering at a bar and kitchen runs on memory, texts and a clipboard. Nobody can say what was ordered, what actually arrived, or what it cost. Backbar is a multi-tenant web app where staff build a shared order list by department, a manager submits it, and a buyer records what was actually received and what was actually paid — so purchase cost history exists from day one."
